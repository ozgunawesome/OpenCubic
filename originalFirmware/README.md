# Original Firmware

This folder contains the official Anycubic ACE firmware, so you can restore your ACE to stock at any time.
Flash either file with the ACE Flash Tool the same way you would flash the CFW (select the `.bin`, then Flash).

## Files

| File | Device | Version | Notes |
|---|---|---|---|
| `ACE_V1.3.863_20250518.bin` | ACE 1 Pro (Gen 1) | v1.3.863 | Raw firmware binary, flashable directly via the tool. CFW v1.0.0 (Gen 1) is based on this. |
| `ACE2_V1.1.31_20260306.bin` | ACE 2 Pro (Gen 2) | V1.1.31 | Raw firmware binary, flashable directly via the tool. CFW v1.0.4 (Gen 2) is based on this. |
