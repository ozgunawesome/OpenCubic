# Original Firmware

This folder contains the official Anycubic ACE firmware binaries.

You can restore your ACE Gen 1 to stock firmware at any time using the ACE Flash Tool —
select the .bin file from this folder and flash it the same way you would flash the CFW.

## Files

| File | Version | Notes |
|---|---|---|
| ACE_V1.3.863_20250518.bin | v1.3.863 | Official Anycubic release — CFW v1.0 is based on this |
